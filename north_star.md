# North star

Every ChessEver frontend (web, mobile, desktop) can turn any library folder or
database into a published collection with the same capabilities: the same
fields, preview, draft/submit/unpublish states, and a real cover-photo upload
that is separate from the profile photo (the profile photo is the author
picture; the cover shows in collection cards). Each app follows its own design
language.

Source: Berkay, dashboard thread, 2026-10-01. Production is the target (the
Test app was retired 2026-10-06, see AGENTS.md).

Status: DONE. Shipped on web, mobile and desktop, and live on production
gamebase (verified 2026-10-07). Do not resume this as an open goal.
