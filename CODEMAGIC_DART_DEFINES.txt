# CodeMagic Dart Define Commands

```bash
flutter build apk --release --flavor production -t lib/main.dart \
  --dart-define=SUPABASE_URL="$SUPABASE_URL" \
  --dart-define=SUPABASE_ANON_KEY="$SUPABASE_ANON_KEY" \
  --dart-define=GOOGLE_WEB_CLIENT_ID="$GOOGLE_WEB_CLIENT_ID" \
  --dart-define=GOOGLE_IOS_CLIENT_ID="$GOOGLE_IOS_CLIENT_ID" \
```

## Notes:

1. The `$VARIABLE_NAME` syntax references the environment variables you've already defined in your CodeMagic dashboard
2. Make sure your CodeMagic environment group contains all variable references above; `ANALYSIS_API_BASE` is a public literal URL and does not need an environment variable
3. The variables are passed at compile-time, making them secure and not visible in the final binary
4. You can copy-paste these commands directly into your CodeMagic build scripts
